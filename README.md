# IGISUBIZO PUMPKIN PROJECT

## Overview
IGISUBIZO Pumpkin Project is a youth-led agro-processing initiative that transforms pumpkins into value-added products such as donuts, juice, and powder. The project reduces post-harvest losses, creates jobs, and improves community nutrition.

## Mission
To empower youth and farmers through sustainable pumpkin value addition.

## Vision
A community where no agricultural produce is wasted and every youth has access to economic opportunities.

## Core Products
- Pumpkin donuts
- Pumpkin juice
- Pumpkin powder

## Status
Prototype and pilot testing completed.
